# Eventora - Event Booking Platform

## Project Overview
Eventora is a MERN stack based event booking platform developed to simplify the process of discovering and managing events. The platform allows users to explore events, register, and manage their bookings through an interactive interface.

## Technologies Used
- MongoDB
- Express.js
- React.js
- Node.js
- JavaScript
- JWT Authentication

## Key Features
- User registration and secure login
- Event browsing and management
- Booking system for events
- Role-based access for users and administrators
- Responsive user interface

## Project Objective
The main objective of this project is to build a complete full-stack web application that provides a smooth event management and booking experience.

## Future Enhancements
- Online payment integration
- Improved recommendation system
- Advanced analytics dashboard
